# 班级花名册

离线使用的班级名单管理与 A4 排版工具，支持网页版和 Windows 便携桌面版，适合整理名单、分组打印和导出 Excel。

## 功能概览

- **多班级管理**：独立维护各班名单、原始顺序与排版设置。
- **便捷导入**：支持从 Excel 粘贴姓名、性别，或直接导入 Excel 文件。
- **A4 实时预览**：男女双列、分组双列、一键适配、自动分页与对称页边距。
- **排版模板**：保存配色、字号、分组和间距，在不同班级间复用。
- **多格式输出**：打印 / PDF、带样式的 Excel、可恢复的 JSON 项目文件。
- **离线运行**：运行时无需联网，提供单文件 HTML 和 Windows 便携 EXE。

## 直接使用

双击 **`班级花名册.html`**，用新版 Edge 或 Chrome 打开即可。所有依赖都包含在该文件中，无需安装、联网或启动服务。可以单独复制这个 HTML 到其他电脑。

网页打开后点击顶部「全屏使用」，即可隐藏浏览器标签栏、地址栏等界面；按 Esc 或点击「退出全屏」恢复。也可使用浏览器 F11。浏览器不允许普通 HTML 在双击打开时自动进入全屏；要求打开即无浏览器界面，请使用 EXE 版。

1. 左侧点击「＋」新建班级，每个班级有独立名单及排版。
2. 从 Excel 复制姓名、性别两列，粘贴后点击「预览导入」；也可以「添加学生」，在列表中修改姓名、性别、顺序或删除。姓名相同允许保留，导入会提醒。
3. 点击「排版设置」，选择男女双列或分组双列。分组保持原始顺序，先左组、再右组、再下一对。默认每组 5 人，同组同色系、组内深浅不同。
4. 右侧实时显示 A4 预览。默认左右页边距和中间留白各 15 mm，两列各 82.5 mm；调整页边距时左右同步，始终等宽对称。
   点击「一键适配 A4」：按实际男女比例或完整分组一次性计算，优先压缩行内留白，再调整组标题、组间距和上下边距，必要时降低字号（最低 9 pt）；仍放不下则自动分页。结果填入排版设置，可继续手动修改并保存为模板，名单变化不会自动重算。修改组人数、组间距会切换到分组模式；两个输入始终可以编辑。预览、打印 / PDF 和 Excel 共用计算后的尺寸，项目与模板保留实际配置。
5. 「打印 / PDF」按右上角范围输出当前班级或全部班级。打印设置选择 A4、100% 比例，关闭页眉页脚并开启背景图形。选择「另存为 PDF」可保存打印稿。

### 表格填写样式

在「排版设置」勾选「启用表格填写样式」，输入 1～12 列空白填写格（默认 2 列）。男女双列中男女各成一张表，分组双列中每组各成一张表；组标题保留在上方，学生行紧密相连，带完整外框及内部横纵格线，不显示任何列表头。序号可隐藏，行高可调整；整行（包括填写格）沿用原有配色及组内深浅变化。男女双列中男生、女生分别从 1 编号，跨页连续；分组双列仍显示原始名单序号。左右留白与组间距沿用原设置。

表格设置随班级、项目与模板保存，打印 / PDF 和 Excel 同步输出空白格与边框。Excel 中的姓名可以在原单元格修改后导回；空白填写格中的后续内容不作为学生资料恢复。

## 保存与恢复

- 「模板列表」会直接列出每个已保存模板的名称和排版摘要，点击对应的「编辑」即可载入该模板；修改后点击「保存模板修改」更新原模板。
- **保存排版**：排版设置中的「保存排版」和模板列表中的「保存为模板」均会提示输入模板名称，保存当前班级参数并创建模板。保存完成后自动打开模板列表，新保存的模板显示在首位；平时修改参数也会自动暂存到当前班级。
- **重新编辑模板**：点击与「人员名单」「排版设置」并列的「模板列表」，在「已保存模板」中找到模板，点击「编辑模板」，自动切换到「排版设置」并载入原参数。修改后点击「保存模板修改」即可更新原模板，无需重新命名。编辑期间当前班级同步显示并保存排版，其他班级已套用的设置不自动改变；切换班级后退出模板编辑状态。
- **排版模板**：点击「保存为模板」命名保存，在其他班级中选择模板后点击「套用」。包含标题、配色、分组、自动适配开关及全部手动参数，不含名单；自动适配会按目标班级人数重新计算。同名保存可确认覆盖，也可删除模板。模板随项目文件、应用导出的 Excel 和本地暂存一起保存；打开项目或恢复应用 Excel 时，模板随整个项目替换。
- **保存项目**：下载 JSON，包含全部班级、原始顺序、姓名性别和完整排版设置。下次「打开项目」恢复；打开前会预览并提示替换当前项目。
- **导出 Excel**：导出全部班级，每班一个可见 Sheet，保留标题、颜色、字号、双列宽度、中间空列、页边距、A4 和手工分页。额外隐藏 Sheet 保存恢复所需数据。
- **导入 Excel**：本应用导出的文件恢复整个项目，并读取展示表原位置的姓名修改；清空原姓名格视为删除该学生。请保留隐藏数据 Sheet。展示表不适合插入、删除、移动行列或修改性别；这些编辑请在应用内进行。页面布局、颜色等设置以隐藏存档为准，外部格式修改不自动反推应用设置。
- **普通 Excel 导入**：每班一个 Sheet，使用姓名、性别两列。可以含表头「姓名、性别」，也支持列序互换。无效行会在确认前列出，有效班级追加到当前项目。
- 浏览器会自动暂存，但清理浏览器数据、更换浏览器或移动 HTML 路径可能影响暂存。**正式保管和迁移请使用项目文件**，HTML 本身不包含后续输入的名单。

Excel 的字体度量和分页与浏览器存在差异；需要固定打印效果时使用 PDF。过长姓名在预览中截断显示，请调整字号；原始名单与导出数据保留完整姓名。实际打印需使用支持上述页边距的打印机。

## 两种发行包

桌面版打包使用 Windows 10/11 x64，推荐 Node.js 22 LTS（CI 使用此版本）。首次安装与打包需联网下载构建依赖，交付给使用者后可以离线运行。

```powershell
npm ci
npm run pack:web
npm run pack:exe
# 或一次生成两种包
npm run pack:all
```

- `release/班级花名册-网页版.zip`：发送 ZIP，解压后双击内部 HTML，在浏览器打开，会显示浏览器标签页。附使用说明，无需安装。
- `release/班级花名册.exe`：只发送这个 EXE，双击以独立窗口最大化运行，无浏览器标签页和地址栏。F11 全屏，Esc 退出全屏。无需安装或手动解压，启动时自动解包临时运行资源。适用于 Windows 10/11 64 位。
- `release/win-unpacked/` 是桌面构建中间产物，不必发送给使用者。

桌面版会在实际 EXE 旁自动创建 `data/`，其中 `project.json` 保存全部班级和设置，`runtime/` 保存运行缓存。请把 EXE 放在可写文件夹中，移动现有数据时关闭程序并一起复制 EXE 与整个 data 文件夹。不要把 data 复制进网页版压缩包。更换版本时保留 data、替换 EXE 即可。数据损坏时不会自动覆盖，请使用已保存的项目文件恢复。

桌面版「打印 / PDF」提供系统打印和直接保存 PDF。导出项目、Excel 时显示文件保存对话框。未配置代码签名证书，构建的是未签名便携程序。

若下载 Electron 超时，可在当前 PowerShell 会话设置镜像后重试：

```powershell
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR='https://npmmirror.com/mirrors/electron-builder-binaries/'
npm ci
npm run pack:all
```

`npm start` 本地运行桌面开发版；`npm run test:desktop` 验证打包后的 `win-unpacked` 程序（先运行 `npm run pack:exe`）。

## 源代码构建

推荐 Node.js 22 LTS，使用 npm 安装锁定版本的依赖。在项目根目录执行：

```sh
npm ci
npm test
npm run build
```

安装了 Microsoft Edge 的 Windows 电脑还可运行 `npm run test:browser`，检查离线页面、名单导入、对称排版、Excel 往返、本地暂存恢复与 PDF 输出。

构建输出为根目录的 `班级花名册.html`。源代码位于 `src/`。Excel 处理使用 xlsx-js-style，ZIP 处理使用 fflate，打包使用 esbuild；运行时不访问 CDN。依赖许可证保留在构建文件中。

## 常见问题

**数据保存在哪里？**

网页版自动暂存于当前浏览器；桌面发行版自动保存到 EXE 旁的 `data/`。建议定期使用「保存项目」导出 JSON，作为备份与迁移文件。

**升级桌面版如何保留名单？**

关闭程序，保留原有 `data/` 文件夹并替换 EXE。迁移到其他位置或电脑时，将 EXE 与整个 `data/` 文件夹一起复制。

**为什么换浏览器或移动 HTML 后看不到名单？**

浏览器暂存与浏览器环境和文件路径有关。使用之前保存的 JSON 项目文件恢复；将 HTML 复制给别人不会同时带上已录入名单。

**打印应该用 Excel 还是 PDF？**

需要固定版式时优先使用 PDF；Excel 适合继续处理表格数据，其字体度量与分页可能与浏览器不同。
